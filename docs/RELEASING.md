# VGTU Release Guide

## Current status

VGTU is pre-alpha. No public, installable Minecraft build is currently available.

## Before a release

- Confirm the project builds successfully.
- Test on the intended Minecraft version.
- Check Vulkan compatibility and rendering stability.
- Document known issues and limitations.
- Update `CHANGELOG.md`.

## Publishing

1. Create a GitHub release.
2. Use a version tag such as `v0.1.0`.
3. Write release notes describing changes.
4. Attach build artifacts only after they have been tested.
5. Clearly identify experimental or unsupported features.

Never label an untested build as stable.
